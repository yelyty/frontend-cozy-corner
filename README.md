# Frontend Cozy Corner

The source of [frontendcozycorner.com](https://frontendcozycorner.com), a personal blog about the frontend.
Astro, no UI frameworks, hand-built design, and plants that fall asleep in dark mode.

## Layout

```text
src/
|---components/ Astro components, including SVG illustrations
|---content/blog Posts as MDX
|---layouts/ BlogPost
|---pages/ Routes
|---styles/ global.css with desing tokens
```
