### A checkbox has three states, not two

On and off are the obvious pair. The one everyone forgets is indeterminate — the "some, but not all" state a parent checkbox shows when its children disagree. There's no HTML attribute for it; you can only set it in JavaScript. A switch looks like a cousin but makes a different promise: it acts the moment you flip it, where a checkbox waits for you to submit.

```css
input[type=checkbox]   { accent-color:#b46060; }

input:indeterminate

```

### The reminder
You don't need all of these on day one. A pet project is allowed to be rough. But the forgotten states are precisely the line between something that feels like a demo and something that feels considered — and they cost minutes, not days.

So next time the happy path looks done, don't ship it yet. Hover it. Tab through it. Empty it out. Unplug the wifi and reload. The little cracks you find are just the project asking, politely, to be finished.
